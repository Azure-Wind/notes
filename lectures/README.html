讲座资料库 · 使用说明

根目录 大学\lectures　·　每场讲座一个文件夹　·　更新于 2026-10-17

01三句话

  • 每场讲座一个文件夹，文件夹里有一份自包含的「正式版笔记」，其余都是它的附属品。
  • 还没有正式版时，从 _模板\ 拿骨架；讲座结束后合并成正式版，并把旧的过程稿清掉。
  • index.html 是脚本生成的产物，不要手改；资料变动后重跑一次 生成索引.py。
只想看内容：打开 index.html → 点「正式版」那一行。要点图片版发到手机或打印，点「图片版（25 张）」。

对象规则示例

附件子目录 附件\，保留原始文件名附件\logits_toy_model.py

一处历史偏差：旧版本说明里写的是固定名 01_讲座笔记_正式版.html，实际采用的是「与文件夹同名」。两种命名索引脚本都能识别（含「正式版 / 笔记」字样即视为正式版；否则把该文件夹里最大的 HTML 视为正式版），所以不必为了统一而改名。

05日期从哪来

文件夹名只放英文标题，日期写进正文页 <head> 的元数据注释，由索引脚本读取显示，因此改名不会丢日期：

<!-- lecture-date: 2026-10-16 | lecture-title: AI智能体：从对话到行动 | lecture-title-en: AI Agents: From Chat to Action -->

同一份 <head> 里的 <title> 会被索引当作友好名称，<meta name="description"> 被当作摘要显示。想让索引里那一条好看，就把这两项写好。

06排版与公式约定

  • 全文正体：公式里的变量、函数名、上下标一律不用斜体。
  • 真下标 / 真上标 / 真分式：用 <sub>、<sup>；分式用 .frac 容器（分子 .num、分母 .den，靠 border-top 画分数线），不要用 x/y 斜杠冒充分式。
  • 三个现成的类：.formula（公式区，带标签列）、.math（行内数学字体）、.frac（分式）。纯 HTML + 内联 CSS 实现，不依赖外部字体或 MathJax，离线可看、可打印。
  • 代码与数值账本保持等宽：矩阵、逐项实算、脚本输出这类内容不要做成排版公式——它要能逐字对齐、逐行核对。
  • 中文正文：无衬线字体栈、行高约 1.7；数学符号可用衬线栈（Cambria Math → Georgia → Times），但同样正体。

07索引与脚本

_脚本\生成索引.py 做四件事：

  1. 扫描根目录下所有不以 _ 开头的文件夹，一个文件夹算一场讲座；
  2. 读 <head> 里的元数据注释得到日期与标题，并按角色给文件分类（正式版 / 讲义 / 预习 / 提问卡 / 总结 / 图片版 / 附件 / 资料）；
  3. 把同一目录下的多张图片折叠成一条记录，显示「图片版（25 张）」，链接指向第 1 张；
  4. 用 <title> 当名称、meta description 当摘要，按日期倒序输出 index.html（同时是打印友好的 A4 版式）。

两种跑法（等价，.ps1 只是包装器）：

python "大学\lectures\_脚本\生成索引.py"
powershell -File "大学\lectures\_脚本\生成索引.ps1"
不要手改 index.html：下次生成会被整份覆盖。要改样式或排序，改 生成索引.py 里的 CSS 与 KIND_ORDER。

08新讲座怎么加

  1. 建文件夹，名用讲座英文标题（连字符代替空格）。
  2. 从 _模板\ 复制 01_讲座笔记.html / 02_讲后总结.html 到新文件夹，作为当场记录与复盘骨架。
  3. 在页头写入 <!-- lecture-date: … | lecture-title: … -->，并写好 <title> 与 meta description。
  4. 讲座结束后合并成正式版（与文件夹同名），需要时导出 图片版\01–NN.png，把可用脚本放进 附件\，删掉过程稿。
  5. 重跑 生成索引.py 刷新 index.html。
对助手可以直接说：「为 X 月 X 日的某某讲座建资料夹」「把这份笔记合并成正式版并导出图片版」「刷新索引」。

09格式与交付约定

  • 所有资料以 HTML 交付：单文件、内联样式、不依赖任何外部资源，离线可看，Ctrl+P 可直接打印成 A4 PDF。
  • 不产出 Markdown 文件；确需其他格式（LaTeX、代码文件等）时按需生成。
  • 正式版是唯一阅读稿：样式、图表、示例代码全部内联；单独转发，或删掉同目录其他文件，都不影响阅读。
