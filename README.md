# 笔记库 · notes

> 手写笔记，亲手做实验。
> 但我有AI帮我排版哈哈。

## 这个仓库是什么

| 环节 | 谁做的 | 说明 |
| --- | --- | --- |
| **内容** | 我 | 上课记的、读书想明白的、做题卡住又弄通的。按主题重排，不按时间顺序。 |
| **实验与数字** | 我 | 文中出现的准确率、耗时、参数规模，都来自我机器上的一次真实运行，代码在文章里，可复现。 |
| **HTML 呈现** | AI | 把我写在草稿里的内容转成单文件 HTML：结构、样式、目录、图表、打印版式。 |
| **索引与脚本** | AI | `rebuild.py`：从各篇文章的 `<head>` 里读标题、摘要、日期，生成三张索引页。 |

**AI 没有做的事**：选题、听课记录、推导过程、写实验代码、判断结论、核对数字。

## 写作约定

- **证据分级**：关键判断标注「讲座 / 通识 / 推断 / 待核」，可疑的地方汇总到待核清单，不混在正文里冒充事实。
- **不伪造引语**：没有录音或逐字稿时，所有「讲者说」都是转述，并明确标注。
- **自己交代局限**：长文都带一节「已知偏差」，写明立场、结构重排、时间性材料未核验等问题。
- **版本可追**：重要文章维护版本表，记录每次改了什么。

## 关于 AI 参与的边界

排版和脚本由 AI 完成，但**内容与数字由我负责**：公式、推导、实验结论我都逐条核对过。如果仍然有错，那是我的错，不是工具的错。

如果你在文中发现事实错误、推导漏洞或过时信息，欢迎开 issue 指出。
