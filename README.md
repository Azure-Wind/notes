# 笔记库 · notes

> 手写的笔记，亲手跑的实验，AI 帮忙做的排版。

这个仓库是我的学习笔记：内容自己写、实验自己跑、页面交给 AI 转成 HTML。

## 这个仓库是什么

| 环节 | 谁做的 | 说明 |
| --- | --- | --- |
| **内容** | 我 | 上课记的、读书想明白的、做题卡住又弄通的。按主题重排，不按时间顺序。 |
| **实验与数字** | 我 | 文中出现的准确率、耗时、参数规模，都来自我机器上的一次真实运行，代码在文章里，可复现。 |
| **HTML 呈现** | AI | 把我写在草稿里的内容转成单文件 HTML：结构、样式、目录、图表、打印版式。 |
| **索引与脚本** | AI | `rebuild.py`：从各篇文章的 `<head>` 里读标题、摘要、日期，生成三张索引页。 |

**AI 没有做的事**：选题、听课记录、推导过程、写实验代码、判断结论、核对数字。

## 为什么是单文件 HTML

每篇文章都是一个自包含的 HTML：样式全部内联，不引用外部字体、CDN 或图片。

- 离线可读：发给别人一个文件就够了，不会掉样式。
- 可直接打印：`Ctrl + P` 选 A4、勾选「背景图形」，就能存成 PDF。
- 好归档：十年后浏览器还能打开，不依赖任何框架和构建工具。

## 怎么读

- **本地**：直接双击 `index.html`。所有站内链接都指向具体文件，不依赖 Web 服务器。
- **线上**：GitHub Pages（`lectures/` 之类的短地址由 Pages 自动回落到 `index.html`）。

## 新增一篇之后

```bash
python rebuild.py           # 重建三张索引页
python rebuild.py --check   # 只检查是否过期（过期退出码 1）
```

索引的标题与摘要**取自文章自己的 `<head>`**：

```html
<title>文章标题</title>
<meta name="description" content="一句话摘要，会显示在索引卡片里">
<!-- 讲座专用，可选 -->
<!-- lecture-date: 2026-10-16 | lecture-title: 中文标题 | lecture-title-en: English Title -->
```

所以想让索引好看，改文章头部即可，不用去动索引文件。

## 写作约定

- **证据分级**：关键判断标注「讲座 / 通识 / 推断 / 待核」，可疑的地方汇总到待核清单，不混在正文里冒充事实。
- **不伪造引语**：没有录音或逐字稿时，所有「讲者说」都是转述，并明确标注。
- **自己交代局限**：长文都带一节「已知偏差」，写明立场、结构重排、时间性材料未核验等问题。
- **版本可追**：重要文章维护版本表，记录每次改了什么。

## 关于 AI 参与的边界

排版和脚本由 AI 完成，但**内容与数字由我负责**：公式、推导、实验结论我都逐条核对过。如果仍然有错，那是我的错，不是工具的错。

如果你在文中发现事实错误、推导漏洞或过时信息，欢迎开 issue 指出。
